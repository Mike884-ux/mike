# Скан

Сайт о крипторынке: цены, капитализация и графики тысячи монет, как на крупных агрегаторах, плюс то, чего там нет: сигналы по индикаторам, разбор рынка от ИИ, портфель, новости и чат с аналитиком.

## Разделы

- **Криптовалюты** (`/`) — главная: строка с общей статистикой рынка, блоки «В тренде», «Лидеры роста и падения», капитализация за 7 дней, индекс страха и жадности; таблица по капитализации с изменениями за 1ч, 24ч и 7д, объёмом, предложением и недельным графиком; вкладки «Избранное», «Растут», «Падают» и категории (ИИ, мемкоины, DeFi, Layer 1, реальные активы, игры); 10 страниц по 100 монет.
- **Страница монеты** (`/coins/bitcoin`) — цена, диапазон за сутки, капитализация, объём, FDV, предложение, ссылки, конвертер, график с периодами от суток до всей истории (линия или свечи), описание, исторические максимум и минимум, сигналы и анализ ИИ.
- **Сигналы, Новости, Портфель, ИИ-аналитик** — для зарегистрированных.
- Поиск монет (клавиша `/`), светлая и тёмная тема, четыре языка.

### Бесплатно на Render

Если Vercel недоступен, сайт работает на бесплатном тарифе Render, без банковской карты. В репозитории есть `render.yaml`, поэтому настройка почти автоматическая:

1. Зайдите на render.com через GitHub и разрешите доступ к репозиторию.
2. **New → Blueprint**, выберите репозиторий, ветку `main`.
3. Render спросит значения: `DATABASE_URL` — строка подключения из Neon; `ADMIN_EMAILS` — ваш email; `PAY_CONTACT` — ваш Telegram; `ANTHROPIC_API_KEY` — ваш ключ Claude API с console.anthropic.com, или `GEMINI_API_KEY` — бесплатный ключ ИИ с aistudio.google.com (без ключа ИИ не будет отвечать). `BETTER_AUTH_SECRET` Render создаст сам.
4. **Apply**. Сборка занимает 5–10 минут, адрес будет вида `https://skan.onrender.com`.

Бесплатный сервер засыпает, если 15 минут никто не заходит: первый визит после этого открывается около минуты, дальше всё работает как обычно. Переменные потом меняются в Render → сервис → Environment.

## Переменные окружения

Задаются в Vercel: Project → Settings → Environment Variables. После изменения нажмите Redeploy.

| Переменная | Обязательна | Зачем |
| --- | --- | --- |
| `BETTER_AUTH_SECRET` | да | Подпись сессий. Любая случайная строка от 32 символов. Без неё все выходят из аккаунта при каждом перезапуске. |
| `DATABASE_URL` | да, для сохранения данных | Postgres. Бесплатно: Vercel → Storage → Neon. Подойдёт и `POSTGRES_URL`. Без базы вход, кошельки, тарифы и сделки теряются, а пользователей выкидывает из аккаунта — сайт покажет об этом предупреждение. |
| `ANTHROPIC_API_KEY` | нет | Свой ключ с console.anthropic.com. Если его нет или он неверный, сайт сам берёт ИИ через Vercel AI Gateway. |
| `ANTHROPIC_MODEL` | нет | Модель Claude, по умолчанию `claude-opus-5`. `claude-haiku-4-5` намного дешевле, но разбирает рынок поверхностнее. |
| `AI_GATEWAY_MODEL` | нет | Модель через Vercel AI Gateway, по умолчанию `anthropic/claude-opus-5`. |
| `AI_GATEWAY_API_KEY` | нет | Нужен только вне Vercel. На Vercel шлюз открывается токеном самого проекта (OIDC). |
| `GEMINI_API_KEY` | нет | Последний запасной ИИ. |
| `APP_HOSTS` | нет | Свой домен, например `scan.example.com`. Адреса `*.vercel.app` подхватываются сами. |
| `COINGECKO_API_KEY` | нет | Бесплатный Demo-ключ с coingecko.com/en/api. Без него сайт тоже работает, с ним CoinGecko реже отвечает «слишком много запросов». |
| `COINGECKO_PRO_API_KEY` | нет | Платный ключ CoinGecko, если он есть. |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | нет | Кнопка «Войти через Google». Ключи из Google Cloud Console → APIs & Services → Credentials → OAuth client ID (Web application). |
| `TWITTER_CLIENT_ID`, `TWITTER_CLIENT_SECRET` | нет | Кнопка «Войти через X». Ключи из developer.x.com → Projects & Apps → User authentication settings (OAuth 2.0, Web App). |
| `RESEND_API_KEY` | нет | Вход по коду из письма. Бесплатный ключ с resend.com. |
| `MAIL_FROM` | нет | Отправитель писем, например `Скан <login@ваш-домен>`. Домен нужно подтвердить в Resend. Без подтверждённого домена Resend шлёт письма только на ваш собственный адрес. |
| `ADMIN_EMAILS` | нет | Ваш email (или несколько через запятую). Открывает панель владельца `/admin`: статистика, выдача тарифов, платежи и ИИ-маркетолог. У админов нет лимитов ИИ. |
| `NOWPAYMENTS_API_KEY`, `NOWPAYMENTS_IPN_SECRET` | нет | Оплата тарифов криптовалютой (USDT, BTC, ETH…). Ключи с nowpayments.io → Settings → Payments. Адрес для уведомлений сайт передаёт сам с каждым счётом (`https://<ваш-домен>/api/billing/nowpayments`). |
| `NOWPAYMENTS_CARD` | нет | Оплата картой Visa/Mastercard через NOWPayments: покупатель платит картой, вам приходит криптовалюта. Сначала NOWPayments должен включить для аккаунта «fiat on-ramp» (письмо на support@nowpayments.io, проверка бизнеса), потом задайте `usd`. У их партнёра по картам есть минимум, поэтому на сайте карта доступна от $20 (`NOWPAYMENTS_CARD_MIN`). |
| `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` | нет | Оплата картой. В Stripe → Developers → Webhooks добавьте `https://<ваш-домен>/api/billing/stripe` с событиями `checkout.session.completed` и `checkout.session.expired`. |
| `PAY_CONTACT` | нет | Оплата переводом на карту: куда писать покупателю — `@telegram_ник`, ссылка или email. Вы отвечаете номером карты, а после перевода выдаёте тариф в `/admin`. |
| `BINANCE_REF`, `BYBIT_REF` | нет | Ваши реферальные коды бирж. Кнопки «Торговать на Binance / Bybit» у монет и сигналов добавят их в ссылку. Без кодов кнопки тоже работают, но без вашего вознаграждения. |
| `CANONICAL_HOST` | нет | Ваш домен, например `skan.ai`. Когда он задан, посетители со старого адреса `*.vercel.app` автоматически попадают на него. Адреса `/api/…` (вход через Google/X, оплата, проверка) продолжают работать и на старом адресе. |

**Тарифы.** Free, Pro и Whale с дневными лимитами ИИ, скидка 20% за год, оплата разовая без автосписаний. Пока онлайн-оплата не подключена, кнопка «Оформить» собирает email в лист ожидания: людям обещано 14 дней Pro при запуске, выдать их можно одной кнопкой в `/admin`. Новый аккаунт получает 3 дня Pro, приглашённый другом — 7 дней, пригласивший — +3 дня Pro за друга (до 30). Цены и лимиты меняются в `src/lib/plans.ts`. Если задан `PAY_CONTACT`, в окне оплаты есть кнопка «Оплатить переводом на карту», а лист ожидания не показывается.

**Оплата из Таджикистана.** Stripe в Таджикистане не работает, а Paddle и Lemon Squeezy не принимают крипто- и финансовые сервисы. Что работает:

1. **Перевод на карту — сразу.** Задайте `PAY_CONTACT` (ваш Telegram). Покупатель пишет вам, вы присылаете номер карты (Алиф, Эсхата, Душанбе Сити…), после перевода выдаёте тариф в `/admin` → «Выдать тариф».
2. **Криптовалюта — автоматически.** Зарегистрируйтесь на nowpayments.io, добавьте кошелёк для выплат (например, адрес USDT TRC20 на Binance), создайте API-ключ и IPN secret, впишите их в `NOWPAYMENTS_API_KEY` и `NOWPAYMENTS_IPN_SECRET`, нажмите Redeploy. Тариф включается сам, когда платёж подтверждён.
3. **Карты Visa/Mastercard — автоматически, после одобрения.** Попросите NOWPayments включить fiat on-ramp, после одобрения задайте `NOWPAYMENTS_CARD` = `usd`.
4. **Эквайринг местного банка — позже.** Нужны ИП и договор с банком; когда банк даст документацию для разработчиков, его можно подключить так же.

**Вход через Google, X и по коду.** Кнопки Google и X видны всегда, а работают, когда заданы ключи; без ключей они вежливо предлагают войти по почте. В настройках Google и X укажите адрес возврата `https://<ваш-домен>/api/auth/callback/google` и `https://<ваш-домен>/api/auth/callback/twitter`.

**ИИ работает без ключа.** На Vercel сайт обращается к Claude через Vercel AI Gateway и входит туда токеном самого проекта, поэтому ключ никуда вставлять не нужно. Vercel даёт на это $5 бесплатно каждые 30 дней. Если шлюз ещё не активирован, сайт так и напишет: откройте в Vercel вкладку AI Gateway и включите его.

Порядок: свой `ANTHROPIC_API_KEY` → Vercel AI Gateway → Gemini. Если ИИ не отвечает, сайт пишет причину. Подробности в Vercel → Logs, поиск по `[claude:direct]`, `[claude:gateway]` или `[ai]`.

## Откуда данные о рынке

Цены, капитализация, предложение, логотипы и недельные графики берутся из CoinGecko. Если он недоступен, сайт сам переключается на CoinPaprika, а в крайнем случае на котировки Binance. Графики на странице монеты строятся по свечам Binance, а для монет, которых там нет, по данным CoinGecko. Все ответы кешируются на сервере и на CDN Vercel, поэтому внешние источники получают примерно один запрос в минуту, а не по запросу на каждого посетителя. Индекс страха и жадности берётся с Alternative.me.

Адреса для страниц: `/api/market/global`, `/api/market/listing?page=1`, `/api/market/trending`, `/api/market/coin/<id>`, `/api/market/history/<id>?range=7d`, `/api/market/search?q=`.

## Что внутри

- **Сигналы.** Баллы от −100 до +100 по восьми индикаторам: EMA 9/21/50, MACD и его ускорение, RSI, Stoch RSI, ADX с +DI/−DI, OBV, полосы Боллинджера, объём. ADX ослабляет сигнал в боковике и усиливает в тренде. Старший таймфрейм подтверждает или ослабляет сигнал.
- **Проверка на истории.** Для каждой монеты правило прогоняется по её прошлым свечам без заглядывания в будущее, сайт показывает долю сработавших сигналов.
- **ИИ.** Получает все эти числа, новости, давление покупателей и индекс страха; отвечает строгим JSON с уровнями, сценариями и рисками. Уровни проверяются на сервере, а уверенность урезается, если ИИ спорит с индикаторами.
- **Сделки и стратегии.** На странице монеты можно записать покупку или продажу в портфель и одной кнопкой спросить ИИ про эту монету. Во вкладке «ИИ → Стратегии» ИИ составляет план под ваш риск, срок и текущий портфель.
- **Аккаунт.** Язык (русский или English), страна, избранное, кошелёк и история сделок хранятся в базе и доступны с любого устройства.
- **Защита.** Не больше 5 попыток входа в минуту и 5 регистраций в час с одного IP, счётчики в базе. Список устройств с IP и выход на них. Защитные заголовки: CSP, HSTS, запрет встраивания в чужие сайты.

## Локальный запуск

```bash
npm install
npm run dev      # http://localhost:8090
npm test         # тесты индикаторов, портфеля, базы, данных о рынке и форматирования
npm run lint
npm run typecheck
```

Без `DATABASE_URL` локально используется встроенная база в папке `.data/`.

Это не инвестиционная рекомендация.
