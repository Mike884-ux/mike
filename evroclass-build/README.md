# Сборка сайта «Евро Класс»

Сам сайт лежит в папке [`../evroclass`](../evroclass): его можно открыть как `index.html` или выложить на любой хостинг без сборки. Здесь — скрипты, которые собирают сайт в один файл, и исходники логотипа.

Нужен только Node.js (любой версии от 18). Запускать из корня репозитория:

| Команда                                     | Что получится в `evroclass-build/dist/`                                                    |
| ------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `node evroclass-build/build-single.cjs`     | `evroclass.html` — весь сайт одним файлом: открывается двойным щелчком, картинки внутри     |
| `node evroclass-build/build-live.cjs`       | `evroclass-live.html` — страница для claude.ai с настоящим логотипом и телефонами          |
| `node evroclass-build/build-artifact.cjs`   | `salon-porog.html` — учебная версия «Порог» без настоящего названия, логотипа и телефонов  |

Папка `dist/` в репозиторий не попадает: файлы в ней всегда можно собрать заново.

## Логотип

- `logo-original.jpg` — скриншот профиля с логотипом, который прислал владелец.
- `logo-868.png` — логотип, вырезанный из скриншота, без телефонов, 868×868. Из него сделан `../evroclass/img/logo.webp` (512×512).
- Значок во вкладке браузера — `../evroclass/favicon.svg`: красный «€» на синем круге, как на логотипе.

## Где что менять

Товары, телефоны, адрес, точка на карте — `../evroclass/js/data.js`. Переводы — `../evroclass/js/i18n.js`. Подробная инструкция — в [`../evroclass/README.md`](../evroclass/README.md).
